# Dracula design docs

This folder contains the MVP design. The [design tracker](design-tracker.md)
indexes open design work.

| Document | Purpose |
| --- | --- |
| [Product and scope](product-and-scope.md) | North stars, goals, non-goals, acceptance |
| [Rules](rules.md) | Authoritative game rules and examples |
| [Architecture](architecture.md) | Components, state, visibility, API, and persistence |
| [Agents and models](agents-and-models.md) | Decider, narrator, Strands, AgentCore, and model configuration |
| [Frontend experience](frontend-experience.md) | Responsive game interface and interaction flow |
| [Evaluation and operations](evaluation-and-operations.md) | Evaluation, deployment, observability, security, and local development |
| [Decisions](decisions.md) | Accepted design choices and omitted features |

Sources of truth are [`NORTHSTARS`](../NORTHSTARS) and the documents in this
folder. The original [starter design](../dracula-agentic-game-design.md) is
historical context and may not reflect later decisions. The tracker records the
status and completion condition for each open item.
