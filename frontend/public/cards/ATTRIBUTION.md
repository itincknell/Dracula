# Card assets

The 52 suited PNG files are copied from Kenney Playing Cards Pack 1.0. Kenney
released the pack under CC0. The project-local `Cards (large)` directory is the
immutable source; `npm run prepare:cards` maps those cards to the canonical
Dracula card IDs.

`V1.jpg` and `V2.jpg` are project-owned Vampire card designs stored in
`frontend/assets/cards/`.

Source: https://www.kenney.nl/assets/playing-cards-pack
