## Verification

Every archive was created sequentially with one zstd thread at process priority
`nice 20`. Before removal, every source path received a file SHA-256 or
directory tar-stream SHA-256.

For every archive class:

- zstd integrity validation passed.
- The archive SHA-256 was recomputed successfully.
- The complete member listing was read and retained.
- The embedded input manifest was extracted and compared.
- One representative original file was extracted and compared byte-for-byte.
- The original was removed only after those checks passed.

The five archived SQLite test databases each returned `ok` from
`PRAGMA integrity_check` before archival.

## Direct removals

Rebuildable caches and generated test/build output were not archived. Removed
material included:

- Main Python bytecode and pytest caches.
- Historical search and teacher caches.
- Historical benchmark caches.
- Old Playwright reports and test results.
- Obsolete package/build output.
- Stale Teacher v2 PID files.
- An empty abandoned Sam-128 corpus directory.

A stale launchd job named
`com.itincknell.dracula.training-003` was also removed. It was no longer a
working training process and repeatedly recreated `output-003` with an error
because its historical CLI no longer existed.

The first cache pass removed `frontend/dist` before the already-running Vite
preview was discovered. The API remained healthy, but the preview returned
404. The same production frontend was immediately rebuilt, the preview
returned HTTP 200 again, and `frontend/dist` is now recorded as retained active
generated output rather than a final removal.

- Recorded human games.
- Both immutable card packs and the selected frontend card assets.
- Current source, tests, docs, contracts, and configurations.
- The selected PPO comparison artifact in `runs/training-004`.
- The guided comparison artifact in `runs/search-warmstart-smoke-001`.
- The response-ranker comparison artifact in
  `runs/teacher-v2-response-ranker-001`.

Those three historical run trees remain because current local comparison code
still references their artifacts by path.
